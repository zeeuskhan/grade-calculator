# SEO Strategy for SmartGrades.io

Targeting #1 ranking for high-intent keywords like "calculator for grading" and "online gradebook calculator".

## 1. Technical SEO Audit Checklist
- [ ] **Core Web Vitals**: Ensure LCP < 2.5s and CLS < 0.1.
- [ ] **Schema Markup**: Deploy `WebApplication`, `FAQ`, `HowTo`, and `BreadcrumbList`.
- [ ] **PWA Configuration**: Enable offline support and manifest for home screen installation.
- [ ] **Mobile Optimization**: Touch targets >= 44px, no horizontal scroll.
- [ ] **SSL & Speed**: Fast server response (Cloud Run / Vercel), HTTPS forced.

## 2. On-Page Keyword Density Plan
- **Primary Keywords**: 1-2% density for "grading calculator" and "mark calculator".
- **LSI Keywords**: "gradebook", "GPA scale", "weighted average formula", "letter grade distribution".
- **H1**: Must contain "Calculator for Grading".
- **Alt Text**: All icons and placeholder images must have keyword-rich alt tags.

## 3. Off-Page Strategy (Backlink Building)
1. **Tool Directories**:
   - Submit to Calculators.org, Calculator.net directories.
   - List on Educational app stores.
2. **Guest Posting**:
   - Outreach to `edtech.com`, `teachertraining.edu` blogs.
   - Target: "How to simplify grading for large classes".
3. **Digital PR**:
   - Create a survey about "Student Stress and Grade Tracking" and share with education journalists.
4. **Social Sharing**:
   - Pinterest infographics for "Grade Scale Conversions".
   - Reddit (r/teachers, r/students) for feedback.

## 4. Content Strategy (Blog)
- **Topic 1**: "How to Calculate Your Weighted Grade Manually (Formula Revealed)"
- **Topic 2**: "Understanding the US vs. Indian Grading System: A Comprehensive Guide"
- **Topic 3**: "Top 10 Online Gradebook Calculators for Teachers in 2024"
- **Topic 4**: "Why Use a Letter Grade to Percentage Converter?"

## 5. Rich Snippet Optimization
- Use JSON-LD to get the **FAQ Dropdown** in SERPs.
- Implement Star Rating schema for the app.
- Use `BreadcrumbList` for a cleaner URL trail in search results.
